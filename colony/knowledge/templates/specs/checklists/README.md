# Checklists

## What this folder holds

One [[build-checklist]] per build of {product}, each tracking that build from the gates that must hold before its first code to the last feature it delivers, and one [[owner-checklist]] per field, each holding the steps only the owner can take in that field. The [[authority]] rule gives this folder its standing, and the [[docs-life-cycle]] rule governs the work each feature carries.
