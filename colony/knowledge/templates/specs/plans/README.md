# Plans

## What this folder holds

The record of every feature's build and every launch. The [[docs-life-cycle]] rule says when each page is written.

## How it is organized

One folder per feature, named after the feature. Each holds either the three spec documents, a [[feature-requirements]], a [[feature-design]], and a [[feature-tasks]] page, or one [[feature-spec]], and the feature's [[reconciliation-report]], written in the change that delivers its last task. One folder per launch holds its [[launch-plan]]. A folder moves to the archive's `plans/` once the [[authority]] rule closes it.

No features yet. Each feature folder gets its line here, newest first, in the change that adds its spec.
