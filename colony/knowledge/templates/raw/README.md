# Raw

## What this folder holds

Outside material frozen at capture, one [[source]] page per original source. The [[authority]] rule says what this layer promises.

## How it is organized

- Every capture lives in a folder named after its origin, even a single capture. No capture sits flat. The folder takes the producer's own name: the publisher, company, project, or author that made the material.
- Each origin folder carries its own readme, and that readme is the catalog of its captures. Each capture gets its line there in the same change that adds it.
- Subject access lives in those lines and in the research reports that cite each source, never in the folder structure, because a capture has many subjects but exactly one origin.

## Pages

No origins yet. Each origin folder gets its line here, in alphabetical order, in the change that creates it.

## Not here

- Anything we wrote ourselves. A summary, a conclusion, or a synthesis is a [research](../research/README.md) report or a [wiki](../wiki/README.md) page, never a source.
